# OPC 22 AgentBridge 展板文案 v18

## 项目背景

项目源于北京云中盖娅科技有限公司开放的真实业务场景。AI Agent 可以持续执行复杂任务，但用户离开电脑后仍缺少自然发起、进度同步与关键确认的轻量入口。项目以 4-6 周为 MVP 周期，选择智能眼镜验证跨设备会话接力。

## 一句话价值主张

离开电脑，用眼镜发起任务、同步进度并确认关键操作。

## 完整交互体验

眼镜语音输入 → VAD/STT 与输入门控 → 注入同一 Agent 会话 → PC Agent 执行 → 状态、文字回复与审批卡同步镜像 → 手势确认或继续语音追问。

## 可复核的原型验证

- 自然语音续接：说一句即可继续同一 Agent 会话，支持退出、重录与“只处理最新一句”。
- 同步镜像闭环：任务状态、文字回复与关键操作自动回传眼镜。
- 跨网接力连通：眼镜经手机中继发现并连接 PC，完成服务发现、设备注册与透明转发。
