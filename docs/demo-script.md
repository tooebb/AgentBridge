# 演示视频脚本：语音输入 → 眼镜审批闭环

> 定位：**语音输入 + 眼镜文字审批**（当前 TTS 语音输出未通，agent 回复以文字卡片显示，别在视频里承诺「语音助手」）。

## 录前准备（2 分钟，别拍进视频）

1. 眼镜 WiFi 连着（GAEA 5GHz）、PC 同一网段，终端停在项目根 `AgentBridge-master`。
2. 手机连眼镜 → CXRLSample 点「启动眼镜 App」。
3. PC 一条命令冷启动（默认就是语音配置，无需手设 env）：

   ```powershell
   .\scripts\start-all.ps1
   ```

   → AudioPort `8788` / STT `8790` / Python 已 pin `D:\environment\Python 3.13.7\python.exe`。

4. 等两个信号：STT 模型加载完（首次 ~15s）+ 日志出现 `audio server listening on :8788`。
5. 眼镜确认 mDNS 连上 Core。
6. **干跑一遍**镜头 2/3，确认识别延迟和审批卡片弹出无误，再正式录。

## 镜头顺序（60–90s）

### 镜头 1（10s）环境就绪

- 拍 PC：`start-all.ps1` 跑完，Core + session daemon 日志滚动。
- 画外音：「一条命令拉起 Core、语音识别、会话守护。」

### 镜头 2（15s）语音发起（核心）

- 拍眼镜 + 说话。眼镜**单击**（无任务时 = 开始聆听），屏幕出现「聆听中…」。
- 说：「帮我新建一个文件 demo.txt，写入 hello」。
- 说完停 1 秒，VAD 自动结束，屏幕闪过「识别中…」→「已识别: 帮我新建一个文件 demo.txt…（处理中…）」。
- 画外音：「麦克风采集 → VAD 切句 → faster-whisper 转文字 → 注入正在跑的 Claude Code 会话。」

### 镜头 3（20s）审批卡片 + 手势审批

- 写文件属高风险，眼镜弹出审批卡片（命令 + 风险分）。
- 眼镜**单击** = approve。
- 画外音：「高风险操作自动镜像到眼镜，单击即批准。」

### 镜头 4（15s）结果回传

- 拍 PC：文件真写入；眼镜卡片显示完成。
- 画外音：「结果回传眼镜，全程不用回电脑前。」

## 兜底

- 识别不稳就退到**纯问答**：说「项目当前状态是什么」，看文字回传（最稳）。
- 想秀拒绝：镜头 3 用**双击** = reject，画外音「双击拒绝，Agent 换方案」。

## 手势速查

| 场景 | 手势 |
|------|------|
| 无任务时开始/停止录音 | 单击 |
| 审批卡 approve | 单击 |
| 审批卡 reject | 双击 |
| 展开详情 | 滑动（view_details） |

## 两个必知的坑

- **TTS 是坏的**：agent 回复只以文字卡片显示、不念出来。
- 手势上下文相关：**无卡片时单击 = 开始/停止录音**；**有审批卡片时单击 = approve、双击 = reject**。
