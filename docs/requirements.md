**【业务场景】AI Agent跨设备交互中间层-北京云中盖娅科技有限公司**

**公司简介：**

**我司主营业务是体系仿真与AI智能体。**

**需求业务场景：** 构建一个面向AI Agent的跨设备交互中间层系统，对Claude Code、Codex等AI Agent产生的任务状态、执行结果、异常信息和审批请求进行结构化处理，并根据手机、智能手表、智能眼镜、耳机等不同设备及用户所处情境，自动生成适合当前终端的信息展示和交互方式。

系统需要将Agent产生的大量复杂信息转换为简短、易读、易听、可操作的内容，使用户在通勤、走路、开会或离开电脑等场景下，仍然能够及时了解Agent任务进度，处理低风险审批、异常提醒和关键决策，减少Agent因等待用户响应而长时间停滞的问题。

**验收标准：** 实现一个AI Agent跨设备交互中间层原型系统。

原型系统至少支持接入一种主流AI Agent，能够识别任务开始、任务执行中、任务阻塞、需要审批、任务失败和任务完成等关键事件，并将事件转换为统一的结构化信息。

系统能够根据不同终端输出相应的交互内容，包括：

1. 面向手机或智能手表生成简短状态卡片、风险提示和可执行操作；
2. 面向耳机生成简洁、自然的语音播报内容；
3. 支持用户执行继续、暂停、批准、拒绝、查看详情等基础操作；
4. 支持从摘要信息跳转查看原始日志、代码变更或相关证据；
5. 对高风险或不适合移动端处理的操作进行拦截，并提示用户返回电脑端完成确认。

原型能够完成至少一个完整业务流程：用户在电脑端启动AI Agent任务，离开电脑后通过移动设备接收任务状态或审批请求，完成交互后，AI Agent继续执行任务并反馈最终结果。

**需求预期：**
4-6周

**可方便在外出时进行vibe coding，具体交付形式待定，可讨论**

用户数据
